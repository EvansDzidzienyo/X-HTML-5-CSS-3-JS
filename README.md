# HTML, CSS and JavaScript Practice

This repository preserves a collection of earlier web-development exercises and static website experiments. The source files are in the `xhtml/` directory.

## What is included

- **HTML pages:** several multi-page website layouts, including a food-business concept and a University-style mock-up.
- **CSS:** page-specific and shared styling experiments.
- **JavaScript:** introductory form-validation functions, image rotation and simple interactive examples.
- **PHP:** an early placeholder exercise; it is not a complete server-side application.
- **Media:** images and short video files used by the examples.

## Run locally

Most pages are static and can be opened directly in a browser:

1. Clone or download this repository.
2. Open the `xhtml/` directory.
3. Open `index.html` in a browser.

Some examples may behave differently when opened from a local file URL. A local static server can be used if needed. The PHP example requires a PHP-enabled server, although the current PHP file contains no meaningful server-side functionality.

## Project status and limitations

This is a **legacy learning repository**, not a maintained or production-ready website. It is retained as evidence of earlier practice with HTML, CSS, JavaScript and basic PHP.

The examples have not been comprehensively repaired or tested. During review, the source showed outdated layout techniques, inconsistent markup, placeholder links, and asset references that may not resolve because media files are stored in the `xhtml/media/` directory. Some pages also contain historical contact details and external social links. Review those details and confirm that they are still appropriate before reusing or publishing the pages as a live site.

Do not use the form-validation examples as security controls. Client-side validation can be bypassed and must be backed by server-side validation in any real application.
